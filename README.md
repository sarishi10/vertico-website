# VERTICO — Corporate & Event Branding Website (GitHub Pages Demo)

Responsive, mobile-friendly website demo based on the 7-page Vertico website structure.

## Preview
Open `index.html` in your browser, or publish with GitHub Pages.

## Upload to GitHub
1. Create a new GitHub repository (for example `vertico-website`).
2. Select **Add file → Upload files**. Upload **all files and the `assets` folder**, preserving the folder structure (or extract this ZIP and use Git).
3. Commit to the `main` branch.
4. Under **Settings → Pages → Build and deployment**, select **Deploy from a branch**, `main`, `/ (root)` and Save.
5. GitHub publishes at `https://YOUR-USERNAME.github.io/vertico-website/` once deployment succeeds.

## Features
- Homepage with hero, demo photo slider, service cards and featured cases
- Service overview and detail pages
- Filterable portfolio and sample project photo galleries
- Catalog categories and sample clothing photos
- About and Contact / Request a Quotation
- Sticky navigation and mobile menu

## Demo photographs
The site uses public Unsplash sample photo URLs. These load **with internet access**. The `assets/*.webp` graphics are bundled offline **fallback placeholders** for failed photo requests. These are not actual Vertico events or products, and the named client projects should not be represented as verified photos.
